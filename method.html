风格排名方法说明

32 个照片风格滤镜的视觉偏好排名——背后的实验设计、统计模型与算法细节。

Pairwise Comparison Bradley–Terry Model 32 Styles ~2763 Judgments

1 测试设计：两两比较

每次向受访者展示同一张照片的两个风格版本，问一个简单的问题——「你更喜欢哪个？」。

为什么不用打分制？

让受访者给每个风格打 1–5 分容易出现「全都给 3 分」的无效数据。两两比较只需做一次二选一，判断更直接、门槛更低。相对偏好比绝对评分更可靠，这是心理测量学中被广泛验证的结论。

2 配对策略：平衡轮转

每个受访者每次做 20 对比较。配对不是完全随机——算法确保每个风格与每个对手的对阵次数大致均衡，避免某个风格只跟弱手打、另一个只跟强手打的不公平情况。

实际数据分布

每个风格的 PK 数在 158–255 之间，个别风格参与率偏低。总数据量约 2,763 条有效对比（已去重）。

3 排名算法：Bradley–Terry 模型

为什么不能只看胜率？

👤
业余棋手
跟街头路人下 100 盘
赢 90 盘 → 胜率 90%
👑
职业棋手
跟世界冠军下 100 盘
赢 50 盘 → 胜率 50%

按胜率排 → 业余棋手第一。这显然荒谬。真正的排名必须考虑对手实力。

风格排名完全同理。实际数据中出现了胜率 53% 排第 5、胜率 46% 排第 4的情况——因为后者更多对上强敌，每一场胜利的含金量更高。

模型原理

Bradley–Terry 模型给每个风格估算一个潜在强度值 π（类似于国际象棋的 Elo 分）。基本假设非常简单：

风格 i 赢风格 j 的概率 = πi / (πi + πj)

如果 πi = 4，πj = 1，则 i 赢 j 的概率是 4 / (4+1) = 80%。强度差距越大，胜率预测越悬殊。

迭代求解

给定所有对战结果，π 值通过以下公式迭代计算，直至数值收敛：

π_i = W_i / Σ_j [ n_ij / ( π_i + π_j ) ] W_i = 风格 i 的总胜场数 n_ij = 风格 i 与风格 j 的对阵次数 π_i = 风格 i 的当前强度估计

所有 π 值初始化为 1.0，通常几十轮迭代后收敛。最终按 π 值从大到小排列即得排名。

🏆 这不是投票，这是体育联赛积分。
赢一个强敌比赢一个弱敌加更多分——所以胜率高的不一定排前面，要看赢的是谁。

5 置信区间与显著性

当样本量约为 250 次 PK 时，胜率的抽样误差约 ±6%（95% 置信水平）。这意味着：

如何解读差距

  • 两个风格的胜率差小于约 12% 时，不能 100% 确定谁更好
  • BT 强度值比单纯胜率更可靠，因为它综合了对手信息
  • 相邻排名之间的差异可能不够显著——但 TOP 3 与后半段之间的差距是非常确定的

6 数据去重

同一受访者、同一对风格，只计算一次。防止误双击导致重复提交，确保每个判断在模型中只贡献一份权重。2026/08 起新增浏览器指纹识别——即使受访者清除 localStorage 或使用无痕模式，同设备同浏览器也会被识别为同一受访者，进一步提升去重精度。

7 数据局限性

7.1 PK 次数不均衡

当前各风格参与对比次数在 158–255 之间，最低与最高相差约 38%。这主要源于两两随机配对的随机波动——并非某个风格被系统性排斥。

Bradley–Terry 模型天然能处理这类不均衡（公式中分母用两两对阵次数而非总次数，互相对冲）。主要影响在于置信区间精度：PK 少（158 场）的风格 CI 半宽约 ±7.8%，PK 多（255 场）的风格约 ±6.2%，低参与度风格的排名浮动空间更大。

7.2 同人跨设备投票

受访者身份通过浏览器 localStorage 存储的 voter_id 来标识。换一台设备（手机→电脑）或换一个浏览器会产生新的 voter_id，同一人的多轮判断会被视为不同受访者的独立判断。

如果某位受访者恰好是「日系1996」的忠实爱好者，在三个设备上各做一轮，ta 的偏好就会以 3 倍权重计入排名。越活跃的受访者在最终排名中话语权越大，这是当前方法的一个已知局限。

2026/08 改进：浏览器指纹

新增的浏览器指纹（基于 User Agent + 屏幕分辨率 + 时区等硬件特征）可在同设备上跨会话识别同一受访者（如清除 localStorage 后重投）。但换设备仍无法检测——这需要登录机制才能彻底解决。

7.3 样本量目标

根据 Wilson 置信区间公式，若要将 95% CI 半宽控制在 ±5% 以内，所需的样本量估算如下：

n = (1.96 / 0.05)² × 0.25 ≈ 384 // 每风格最少 PK 数 N = 384 × 32 / 2 ≈ 6,144 // 总判断数

当前数据约 2,763 条、平均每风格 173 次 PK，距离 5% CI 目标还需约 3,600 条新增判断。

当前进度：每风格 PK 数 (158–255) → 95% CI 半宽约 ±6%–±8%。
目标：每风格 PK 数 ≥ 385 → 95% CI 半宽 ≤ ±5%。还需约 3,600 条有效判断。
